# 🔍 Cloud Bill Auditor (مفتش الفواتير السحابية الذكي)

تطبيق ذكي يستند إلى الذكاء الاصطناعي (Gemini API) لتحليل وتفتيش فواتير الخدمات السحابية (AWS & Google Cloud) واكتشاف الهدر المالي فورياً.

🔗 **جرب التطبيق مباشرة عبر الرابط التالية:**
[إضغط هنا لتشغيل التطبيق](https://cloud-bill-auditor-dkfoj46cszrepbeywpe2bu.streamlit.app)

## ✨ المميزات الأساسية:
- 🌐 دعم كامل للغتين العربية والإنجليزي.
- 💰 حساب المبالغ القابلة للتوفير بدقة من الخدمات الخاملة والمستغلة جزئياً.
- 📥 تصدير التقرير النهائي كملف نصي.
- 🔐 حماية كاملة ومجانية باستخدام مفتاح API الخاص بالمستخدم.
